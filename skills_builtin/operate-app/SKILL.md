---
name: operate-app
description: Reliable way to use any Windows app: focus it, list its controls, click by name, verify.
---
1. open_app (or focus_window if it is already open). Wait 1-2 seconds.
2. Prefer ui_list to see the buttons, fields and menus by name, then ui_click / ui_type with those exact names. This is more accurate than guessing pixels.
3. If the app does not expose controls (games, some web pages), use the screenshot: click by coordinates, and use zoom to read small text.
4. After every important step, look and confirm the result before moving on. If something did not change, try a different way.
5. Keyboard shortcuts (ctrl+s, ctrl+f, alt+tab, win+d) are the most reliable option when they exist.
