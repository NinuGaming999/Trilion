---
name: research-topic
description: Research a question on the web and give a short, sourced spoken answer.
---
1. Run web_search with a short precise query. Run a second search with different wording if the first results look weak.
2. Pick the 2-3 most relevant results and read them with fetch_url.
3. Compare them. Prefer official sites, documentation and well-known publications.
4. Answer in 2-4 spoken sentences, say which sites you used, and mention disagreements between sources.
5. If the user wants details saved, use the take-notes skill.
